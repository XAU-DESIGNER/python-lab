مثال کاربردی و مهم:
`ns = "0123456789"`
`ns[5]` => 5
`ns[2:6]` => 2345 (ignores 6)
`ns[2:9:3]` => 258
`ns[1:-1]` => 12345678
`ns[3:]` => 345678
`ns[:-4]` => 012345
`ns[::-1]` => 9876543210
با استفاده از `"""` میشه داخل text اینتر زد
رشته `string` ها `imutable` هستن

>تو پایتون همه چیز کلاسه

تابع `split`:
روی رشته اجرا میشه و یک کاراکتر میگیره و بر اساس اون رشته رو به لیست تبدیل میکنه
`likes = "asd,asdf"`
`likes_list = likes.split(",")` => `[asd , asdf]`
